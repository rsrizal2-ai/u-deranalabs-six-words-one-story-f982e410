One complete story in exactly six words, written for make.fun's "Six Words, One Story" bounty: a farewell that never happens, in a single line the reader finishes for themselves.

## The entry

> Sold the house. Kept the key.

Six words, 29 characters. A sale and a refusal to let go in the same breath — the turn is the kept key, and the why (grief, attachment, a return still planned) stays unsaid.

## Run it

```sh
node main.ts
```

It writes the story to `/output/entry.txt` (or `$OUTPUT_PATH`).
